# 推特会员多少钱：X Premium 三档价格对比，没有海外信用卡也能用微信开通

先把数字给你，省得翻半天。

X（原推特）的个人会员现在分三档，美国区网页端标价是：Basic 每月 3 美元、Premium 每月 8 美元、Premium+ 每月 40 美元。年付分别是 32、84、395 美元。

这是网页端价格。同一个会员在 iPhone 或安卓 App 里买会贵一截，因为苹果和谷歌要抽成，X 官方帮助文档里也明确提示过应用内价格更高。

如果你搜到的文章写 Premium+ 是 16 美元一个月，那是 2023 年刚推出时的老价格。2025 年 Grok 3 上线后它涨到了 40 美元，不少没更新的攻略还在沿用旧数字。

## 三档标价和年付折扣，差在哪

年付比月付便宜，但便宜幅度不一样：

- **Basic**：3 美元/月，年付 32 美元，折合每月约 2.67 美元
- **Premium**：8 美元/月，年付 84 美元，折合每月 7 美元
- **Premium+**：40 美元/月，年付 395 美元，折合每月约 33 美元

Premium 这一档的年付折扣最实在，一年少花 12 美元。Basic 年付只省 4 美元，Premium+ 年付省 85 美元，但它的基数本来就大。

有个前提：年付是一次性付掉全款，中途想退基本没戏。如果你只是想试试蓝标有没有用，先买一个月，别一上来就锁一年。

## 手机里订阅，为什么要多花钱

App Store 和 Google Play 会对订阅抽成，X 把这部分成本转到了标价上。第三方整理的近似值是：Basic 约 4 美元/月、Premium 约 11 美元/月、Premium+ 约 50 美元/月，整体比网页端高出 25% 到 30%。

同一个会员，同一个账号，换个入口就能省十几美元。想省钱的话，绕开 App 内购，走网页端下单。

需要说明的是，应用内这组数字来自第三方汇总，各家写法略有出入，X 官方公布得比较完整的只有网页端价格。你实际看到的金额，以订阅页面上显示的当地价为准。

## 每一档到底买到什么

**Basic（3 美元）** 更像一个功能包，不是身份标识。你能编辑已发的帖子、发更长内容、获得一点回复加权，但账号上不会出现蓝标。想要认证标志，起步得买 Premium。

**Premium（8 美元）** 是大多数人真正需要的那一档。蓝标认证、主时间线广告减少约一半、达到门槛后参与创作者广告分成、Grok 使用额度高于免费版。分成门槛是 500 名关注者加上最近三个月 500 万次展示。

**Premium+（40 美元）** 在上面基础上加：几乎看不到广告（只剩赞助内容）、最大幅度的回复加权、X Pro（原 TweetDeck）、Articles 长文排版、Radar 话题监测、完整版 Grok 额度。

### X Pro 被划走这件事

2026 年 3 月 26 日起，X 把 X Pro 从 8 美元的 Premium 挪到了 40 美元的 Premium+，没有提前通知用户。原本花 8 美元就能用的多栏面板，现在要多掏五倍的钱。

这条改动直接改变了第三档的性价比逻辑：如果你重度依赖 X Pro 做内容监控，Premium+ 从"可选"变成了"唯一选项"；如果你根本不用 X Pro，那多出来的 32 美元买的主要是"没有广告"和"更大的回复加权"。

后一项值不值，取决于你的玩法。做回复引流、靠评论区涨粉的账号，回复权重是实打实的收入来源。只是刷时间线、偶尔发两条的人，8 美元的 Premium 就够了。

## 价格按地区走，不是所有地方都收美元

X 的定价跟着当地货币和税率浮动，同一档在不同地区换算回美元并不相等。

以日本区网页端标价为例（官方帮助中心页面核对）：Basic 每月 368 日元、Premium 每月 980 日元、Premium+ 每月 6,080 日元，年付分别是 3,916、10,280、60,040 日元。

把日元价格换算一下会发现，它和美国区标价并不严格对齐——这就是为什么网上有人讨论"换区订阅"。实际操作上，标价、可用的支付方式、账单地址这些是绑在一起的，换区并不只是改个数字那么简单。

## 国内用户卡住的其实不是价格

搜"推特会员多少钱"的人，多半已经知道大概价位，真正的问题在后面一步：怎么付钱。

X 的订阅走的是国际支付通道，国内的银联卡、大部分人民币卡刷不过去。很多人手里有 Visa 或 Mastercard，照样在付款页面被拒——原因往往不是余额，是发卡行和风控策略。

于是就有了两条路：自己折腾虚拟信用卡，或者找代订阅服务。

虚拟卡的问题是稳定性。开卡有成本、充值有手续费、风控说封就封，用一段时间失效的情况并不罕见。更麻烦的是余额——卡不用了，里面的钱未必取得出来。

另一条路是找平台代为完成订阅。这类平台的作用很窄，就是替你把支付那一段跑通，用人民币付款，剩下的事它处理。

（补充一句：如果你已经有稳定可用的海外卡，且支付一直正常，直接用官方渠道就行，没必要绕。第三方服务解决的是"付不进去"这个问题，不是"更划算"。）

## 常见问题

**为什么价格会变？**

X 的订阅政策和价格属于"随时可能调整"的范围，官方条款里写明了功能与定价可变更。2026 年 3 月把 X Pro 挪到 Premium+ 那次改动，就是没有事先通知的。

**有消息说 X 要出四档 Grok 订阅，是真的吗？**

有媒体报道称正在评估一套从免费到 100 美元 Ultra 的四档方案，但截至目前只停留在"考虑中"，官方没有发布定价页面。别按传闻做购买决定。

**SuperGrok 包含在 Premium+ 里吗？**

不含。SuperGrok 是 xAI 的独立订阅，需要另外付费，跟 X Premium+ 是两笔账。

**年付能中途退吗？**

基本上不能。虚拟服务的订阅一旦开通，退款通常只在平台自身出问题时才处理。所以不确定要不要长期用，先买一个月。

**用第三方代订阅，账号会有风险吗？**

风险点主要在授权方式。要求你交出账号密码的服务要格外小心；只要求会话凭证（Session）或用你自己账号完成订阅流程的，风险相对低一些，但也意味着你要信任平台。另一个变量是平台自身能不能长期运营——个人订阅按月买、月月续，比一次性买长期套餐更稳妥。
